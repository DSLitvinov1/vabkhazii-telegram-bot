# @VAbkhazii — ежедневный Telegram-бот

Бот ежедневно в 09:00 по времени `Asia/Tbilisi`:

1. Берёт свежий прогноз для Гагры, Рицы, Нового Афона и Восточной Абхазии через Open-Meteo.
2. Берёт температуру моря и высоту волны у побережья Гагры через Open-Meteo Marine API.
3. Формирует пост «Абхазия сегодня».
4. Публикует его в `@VAbkhazii` через Telegram Bot API.

## Что нужно один раз сделать владельцу канала

1. В Telegram открыть `@BotFather` → `/newbot` → создать бота.
2. Скопировать выданный токен. Не публиковать его и не отправлять посторонним.
3. В `@VAbkhazii` открыть: Управление каналом → Администраторы → Добавить администратора → выбрать созданного бота.
4. Дать боту минимум право **публиковать сообщения**.
5. Создать приватный репозиторий GitHub и загрузить в него содержимое этой папки.
6. В GitHub: Settings → Secrets and variables → Actions → New repository secret.
7. Имя секрета: `TELEGRAM_BOT_TOKEN`. Значение: токен из BotFather.
8. Открыть Actions → `Daily VAbkhazii Telegram post` → Run workflow, чтобы сделать тестовую публикацию.

## Безопасность

Токен Telegram нигде не хранится в коде. Он должен находиться только в GitHub Actions Secret.

## Важно

Бот использует погодные модели, а не фактические данные о состоянии дорог. Поэтому он не сообщает, что конкретная дорога открыта или безопасна. Для горных маршрутов текст специально содержит предупреждение проверять локальную обстановку перед выездом.
